# REHOTEQ Field — V1

**The field assistant for technicians.** *Diagnose it. Prove it. Get paid.*

V1 deliberately contains **no AI**. The troubleshooting library is curated and
deterministic: it works offline, costs nothing per query, and cannot give anyone
a dangerous answer. The AI (V2–V4) gets earned later, on top of the job corpus
this app collects.

## Engineering notes worth knowing

**PDF without a library.** `pdf.js` writes PDF 1.4 directly: A4, Helvetica
standard-14 fonts, JPEGs embedded raw via DCTDecode. No jsPDF, no CDN, works
with no signal. Verified against `pypdf` — text extracts cleanly, images embed,
pagination and footers are correct.

**QR without a library.** `qr.js` is a byte-mode, ECC-level-M encoder covering
versions 1–6. Its output was verified **bit-for-bit identical** to the reference
`qrcode` npm library across multiple inputs, including mask selection.

**Currency.** ₦ is not in WinAnsiEncoding, so PDF amounts print as
`NGN 25,000.00`. Embedding a TTF fixes this properly — noted as a Phase-2 item.

**Backup was the gap.** The first build could export but not import — which
isn't a backup. It now does both, including photos, and restores by *merging*
so a restore can never destroy newer work. Verified by an automated
export → wipe → restore → verify round-trip.

**Known limitation.** Photos are compressed client-side to ≤350 KB for Nigerian
data costs. On a very old phone, compression of a 48 MP image can take a second
or two.

## Tests

```
npm install
npm test
```

59 automated checks in four suites: a full walkthrough of every screen and
action, a backup round-trip, and a **wiring audit** that scans every button on
17 screens and fails if any tap would hit undefined code, and a **domain guard**
that fails if any printed link points at a domain we don't own. Run it after any change.

Two things are harness limits, not app bugs: jsdom has no canvas backend and
never decodes images, and `fake-indexeddb` destroys `Blob` instances on clone —
so photo *bytes* can't be round-tripped through the harness. The base64
helpers are unit-tested directly to cover that gap.

## Next three steps

1. **Run 20 real REHOTEQ jobs through this app.** Not paper — the app. Every
   gap you hit is a bug worth more than a week of theorising.
2. **Write the troubleshooting library up to ~60 entries.** `data.js` ships 12.
   Dictate the rest from jobs you've actually done. This is V1's "AI".
3. **When 100 job cards exist**, stand up Supabase and swap the bodies of the
   functions in `db.js`. Nothing else in the app touches storage directly, so
   that's the only file that changes.
